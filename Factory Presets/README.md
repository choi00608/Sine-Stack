# Sine Stack Factory Bank

플러그인 상단에서 **Factory**를 선택한 뒤 사운드 목록 또는 이전·다음 버튼을 사용하세요. 열 가지 사운드는 AU·VST3·Standalone 내부에 포함되어 있어 이 폴더를 따로 복사하지 않아도 됩니다. 테마와 사운드 프리셋은 서로 독립적입니다.

| 프리셋 | 용도 | 특징 |
|---|---|---|
| 01 Neon Sub | 베이스 | 둥근 사인파, 은은한 새추레이션, 모노 레가토 |
| 02 Copper Bass | 베이스 | 톱니파·서브, 드라이브, 어두운 24dB 필터 |
| 03 Laser Lane | 리드 | 사각파, 레가토 글라이드, 유니즌과 템포 딜레이 |
| 04 Glass Pluck | 플럭 | 짧은 사인파·5도 배음, 점8분음표 핑퐁 딜레이 |
| 05 Velvet Keys | 키보드 | 부드러운 새추레이션, 코러스·스테레오 트레몰로 |
| 06 Afterglow Pad | 패드 | 느린 어택, 넓은 톱니파 유니즌, 따뜻한 리버브 |
| 07 Airlock Pad | 앰비언트 패드 | 사인파·노이즈, 천천히 움직이는 필터·페이저 |
| 08 Circuit Pulse | 리듬 | 코드를 누르면 DAW 템포의 8분음표로 움직이는 LFO |
| 09 Prism Bell | 벨 | 밝은 사인파 하모닉스, 긴 디케이·공간감 |
| 10 Arcade Orbit | 모션/FX | 움직이는 밴드패스 필터, 페이저·핑퐁 딜레이 |

베이스·리드는 단음 연주, 패드·키·리듬은 코드 연주를 권장합니다. 플럭·벨은 Sustain이 0이라 건반을 오래 눌러도 자연스럽게 감쇠합니다. 동기화된 딜레이/LFO는 호스트 템포를 따르며, 호스트 템포가 없는 경우 플러그인의 120 BPM 기본값을 사용합니다.

**Save Preset**으로 수정한 소리를 저장하면 **User** 뱅크에 사본이 나타납니다. Factory 원본은 덮어쓰지 않습니다. 뱅크를 바꾸는 것만으로 소리가 바뀌지는 않으며, 목록의 항목이나 화살표를 눌러 불러옵니다. 기존 프로젝트를 열 때 저장된 설정을 기본 프리셋으로 덮어쓰지 않습니다.

이 폴더의 `.sinestack` 파일은 같은 사운드를 파일 형태로 내보낸 것입니다. **Load Preset**으로 열 수 있고, 내용은 일반 텍스트 JSON입니다. `Audio Previews/`에는 120 BPM, 48 kHz, 스테레오 24-bit WAV의 8초 연주 예시가 있습니다. 미리듣기에만 시작·끝 페이드를 적용했으며 프리셋 자체는 변경하지 않았습니다. 프리셋 전용 ZIP에는 WAV가 포함되지 않습니다.

재생성: AU 프로젝트의 `SineStackChecks --export-factory /absolute/path/to/Factory-Presets`를 실행합니다. 생성 시 44.1/48 kHz 출력, 음량·클리핑, 최대 폴리포니, 프리셋 저장·복원과 초기 브라우저 동작을 함께 검사합니다.

카테고리는 **Factory / User** 옆 **All categories** 메뉴에서 고릅니다. Bass, Lead, Pad, Keys, Pluck, Bell, Rhythm, Atmosphere, Motion, FX, Other, Uncategorized를 지원하며, 이전·다음 버튼도 필터에 맞는 소리 안에서만 이동합니다. 카테고리나 뱅크만 바꾸면 현재 소리는 유지됩니다.

**Save Preset → Category → Continue** 순서로 카테고리를 선택한 뒤 파일 이름과 위치를 정합니다. `.sinestack` 확장자와 읽을 수 있는 JSON 형식을 유지하며 `category` 메타데이터를 함께 저장합니다. 카테고리가 없던 기존 파일은 **Uncategorized**에 표시됩니다. 기존 파일을 불러와 다시 저장하면 카테고리를 지정할 수 있습니다. 사용자 목록은 기존과 같이 마지막으로 불러오거나 저장한 파일의 폴더를 기준으로 하며, 외부에서 파일을 수정했다면 **Refresh**를 누르세요.
